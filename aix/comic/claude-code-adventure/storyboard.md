# Storyboard：《第一次进入代码迷宫：Claude Code 入门冒险》

## 基本信息

- 标题：第一次进入代码迷宫：Claude Code 入门冒险
- 页数：7（1 封面 + 6 内容页）
- 读者：完全新手
- 风格：concept-story / manga / warm / standard

## Symbol Mapping Table

| 知识点 | 视觉符号 | 迷宫隐喻 |
|--------|----------|----------|
| Claude Code 不是魔法 | 终端窗口 + 握手图标 | 迷宫入口的向导 |
| 清晰任务 | 醒目的任务卡片 | 迷宫中的路标 |

## 角色弧线

- 封面：小岚站在迷宫入口，犹豫张望。
- 第 1 页：遇到 Claude Code，从"它能替我搞定"转变为"它和我一起走"。
- 第 2 页：学会把模糊愿望变成清晰任务，获得第一张任务卡片。
- 第 3 页：学会先读地图再动手，避免盲改。
- 第 4 页：学会先画路线图，再一步步走。
- 第 5 页：学会看命令卡片上的内容，理解每一步。
- 第 6 页：到达迷宫出口，验证成果，确认边界安全，自信走出。

## 封面

**标题**：第一次进入代码迷宫

**画面**：小岚站在巨大的代码迷宫入口前，身后是模糊的城市天际线。迷宫墙壁由代码行构成，入口上方悬浮着一个发光的终端窗口。小岚抱紧笔记本电脑，表情紧张但好奇。

**文字**：副标题「Claude Code 入门冒险」放在画面下方。

---

## 第 1 页：不是魔法，是协作

**学习点**：Claude Code 不是自动驾驶，而是结对编程伙伴。

**面板 1**：小岚冲进迷宫，挥手喊「帮我写个 App！」。迷宫墙壁上的代码乱成一团。

**面板 2**：悬浮终端窗口出现，显示「你好，我是 Claude Code。让我们一起看看你的项目。」小岚惊讶抬头。

**面板 3**：对比画面——左半边是小岚幻想的"魔法棒一挥代码自动生成"，画上大红叉；右半边是小岚和终端窗口并肩走在迷宫中，画上绿色对勾。

**面板 4**：路标牌亮起，写着「协作，不是魔法」。小岚点头，开始和终端窗口并排走。

---

## 第 2 页：把愿望变成任务

**学习点**：清晰任务比模糊请求更有效。

**面板 1**：小岚对终端窗口说「帮我修一下那个 bug」。终端窗口显示困惑的问号，迷宫前方岔路模糊不清。

**面板 2**：小岚重新组织语言，拿出一张发光的任务卡片，上面写着「修复登录页面点击提交后无响应的问题」。

**面板 3**：终端窗口收到清晰任务后，迷宫岔路变清晰，一条路亮起。终端显示「好的，让我先看看登录页面的代码。」

**面板 4**：路标牌亮起，写着「说清楚，才能帮到你」。小岚手持任务卡片，自信微笑。

---

## 第 3 页：先读地图

**学习点**：修改前要理解项目上下文。

**面板 1**：小岚急着动手改代码，伸手去碰迷宫墙壁上的代码行。终端窗口拉住她，显示「等一下，先让我看看项目结构。」

**面板 2**：终端窗口展开一幅迷宫地图卷轴，上面标注了文件结构和依赖关系。小岚凑近查看。

**面板 3**：小岚理解了项目结构后，迷宫墙壁上的代码变得清晰有序。她指着地图上的一处说「原来这个文件和那个是连着的！」

**面板 4**：路标牌亮起，写着「先读地图，再动手」。小岚和终端窗口一起查看地图。

---

## 第 4 页：先计划再行动

**学习点**：复杂任务要先计划，再小步执行。

**面板 1**：小岚面对一长段需要重构的迷宫通道，想一口气冲过去。终端窗口拦住她。

**面板 2**：终端窗口在地面上画出分步路线图：第 1 步 → 第 2 步 → 第 3 步，每步都是一小段通道。

**面板 3**：小岚按照路线图，一步步走。每完成一步，对应的路线亮起绿色。

**面板 4**：路标牌亮起，写着「计划先行，小步前进」。小岚站在已完成的路线上，回头看走过的路都亮着。

---

## 第 5 页：命令不是黑箱

**学习点**：命令执行结果要可见、可解释。

**面板 1**：终端窗口执行一个命令，迷宫地板上出现一张发光的命令卡片，上面显示命令内容。小岚弯腰拾起卡片。

**面板 2**：卡片放大展示，显示命令和执行结果。小岚仔细阅读卡片上的文字。

**面板 3**：小岚对终端窗口说「这个输出是什么意思？」终端窗口解释结果含义，卡片上出现注释标注。

**面板 4**：路标牌亮起，写着「每一步，看得见」。小岚手持卡片，表情安心。

---

## 第 6 页：验证与边界

**学习点**：完成前要验证结果，并尊重安全边界。

**面板 1**：小岚到达迷宫出口，准备冲出去。终端窗口变成一面盾牌挡在出口前，显示「先验证一下。」

**面板 2**：小岚拿起放大镜检查 diff 和测试结果。迷宫出口处出现一个检查站，屏幕上显示测试通过的绿色标记。

**面板 3**：小岚尝试让终端窗口执行一个危险操作，终端窗口显示红色警告「这个操作有风险，需要你确认。」小岚停下来思考。

**面板 4**：小岚通过检查站，自信走出迷宫。终端窗口悬浮在身旁，迷宫外的阳光照进来。画面下方排列 6 个发光的关键词徽章图标：协作、清晰、理解、计划、可见、验证。每个徽章仅显示关键词，不出现完整长句。
