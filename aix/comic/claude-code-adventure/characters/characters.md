# 角色参考图：Claude Code 入门冒险

> **版面说明**：角色参考图使用 4:3 横版构图，因为需要并排展示小岚、Claude Code 悬浮终端窗口和代码迷宫元素；各页面图仍使用 3:4 竖版。

## 小岚（主角）

- 身份：编程新手，第一次打开终端的大学二年级学生。
- 外貌：短发女生，戴圆框眼镜，穿暖橙色系连帽卫衣，背一个贴满贴纸的笔记本电脑包。
- 表情范围：困惑 → 好奇 → 顿悟 → 自信。
- 常见姿态：抱笔记本电脑、探头看屏幕、竖起拇指确认。
- 颜色基调：暖橙色系，代表成长和温度。

## Claude Code（导师 / 悬浮终端窗口）

- 身份：终端中的 AI 编程助手，以悬浮在画面中的终端窗口形象出现。
- 外貌：深色半透明终端窗口，左上角有三个圆点（红黄绿），窗口内显示简洁提示符 `>` 和闪烁光标。窗口边缘有柔和的蓝紫色光晕。
- 表情范围：终端文字本身就是表情——用简短文字回应、提问、确认。
- 常见姿态：悬浮在小岚旁边或头顶，窗口大小随内容变化。小岚提问时窗口微微靠近，执行命令时窗口放大展示。
- 颜色基调：深蓝底色 + 蓝紫色光晕 + 绿色提示符。

## 代码迷宫（场景元素）

- 外观：由代码行、文件图标、文件夹路径构成的迷宫墙壁。墙壁上的文字会随剧情变化——困惑时文字模糊乱码，理解后文字清晰整齐。
- 迷宫中有发光的路标牌，上面写有学习要点关键词。
- 迷宫地板上有发光的命令卡片，拾起后放大展示。

## 禁止项

- 不给 Claude Code 画人形或拟人化身体（只有终端窗口）。
- 小岚不做夸张的动漫变形（如巨大汗滴、爆炸头），保持温暖的日常感。
- 不出现真实品牌 logo 或受版权保护的界面截图。
