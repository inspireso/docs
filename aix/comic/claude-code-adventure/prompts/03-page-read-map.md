# 第 3 页：先读地图

## 页面标题

先读地图

## 面板描述

**面板 1**：小岚急着动手，伸手去触碰迷宫墙壁上的代码行，想要直接修改。终端窗口伸出一道柔和的光线拉住她。终端窗口内显示：「等一下，先让我看看项目结构。」

**面板 2**：终端窗口展开一幅迷宫地图卷轴，卷轴上标注着文件树和依赖关系箭头。小岚凑近仔细查看，表情从急切变为专注。

**面板 3**：小岚理解了项目结构后，迷宫墙壁上的代码行变得清晰有序。她指着地图上的一处连线说：「原来这个文件和那个是连着的！」

**面板 4**：路标牌亮起，写着「先读地图，再动手」。小岚和终端窗口一起查看地图卷轴，准备行动。

## 文字要求

- 地图卷轴上的文件名简单示意即可（如 `main.py` → `utils.py`），不要复杂目录树。
- 对话气泡不超过 14 个汉字。
- 终端窗口内只显示 1 行简短文字。
- 不渲染完整项目文件列表。

## 禁止项

- 不绘制密集终端小字或完整文件树。
- 不给终端窗口画人形。
- 不出现真实品牌 logo。
