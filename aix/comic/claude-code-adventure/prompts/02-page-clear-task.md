# 第 2 页：把愿望变成任务

## 页面标题

把愿望变成任务

## 面板描述

**面板 1**：小岚对悬浮终端窗口说了一句模糊的话。迷宫前方出现岔路，道路模糊不清。对话气泡：「帮我修一下那个 bug」。终端窗口显示一个困惑的问号。

**面板 2**：小岚重新思考，手中出现一张发光的任务卡片。卡片放大展示，上面用大字写着：「找入口和测试」。

**面板 3**：终端窗口收到清晰任务后，迷宫岔路变清晰，其中一条路亮起温暖的光。终端窗口内显示：「好的，让我先看看登录页面的代码。」

**面板 4**：路标牌亮起，写着「说清楚，才能帮到你」。小岚手持发光的任务卡片，自信微笑。

## 文字要求

- 任务卡片上的文字大号、清晰可读，不超过 12 个汉字。
- 对话气泡不超过 14 个汉字。
- 终端窗口内只显示 1 行简短回应。
- 不渲染终端命令输出。

## 禁止项

- 不绘制密集终端小字。
- 不给终端窗口画人形。
- 不出现真实品牌 logo。
