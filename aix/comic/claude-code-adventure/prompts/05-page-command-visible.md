# 第 5 页：命令不是黑箱

## 页面标题

命令不是黑箱

## 面板描述

**面板 1**：终端窗口执行了一个命令，迷宫地板上出现一张发光的命令卡片，上面显示简短的命令内容。小岚弯腰拾起卡片，好奇地看着。

**面板 2**：命令卡片放大展示，卡片背景为深色，上面用大号白色等宽字体显示一行命令，下方用小号字体显示一行简短结果摘要。

**面板 3**：小岚歪头看卡片，对话气泡：「这个输出是什么意思？」终端窗口在卡片旁边添加注释标注，用箭头指向关键部分。终端窗口内显示简短解释文字。

**面板 4**：路标牌亮起，写着「每一步，看得见」。小岚手持命令卡片，表情安心，继续向前走。

## 文字要求

- 命令卡片上的命令使用大号等宽字体，最多 1 行。
- 结果摘要不超过 10 个汉字。
- 注释标注简洁，每个标注不超过 8 个汉字。
- 对话气泡不超过 14 个汉字。
- 不渲染完整的终端输出流。

## 禁止项

- 不绘制密集终端小字或长篇输出。
- 不给终端窗口画人形。
- 不出现真实品牌 logo。
